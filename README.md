# Nodo La Pomona

Herramienta para planificar el cuarto de equipos del nodo La Pomona (MBO35, Maracaibo): plano 2D, vista 3D, medición sobre fotos, distribución del rack y cotización de materiales y equipos.

Página publicada: https://keinerjbrachoc-jpg.github.io/nodo-la-pomona/

Fuera de claude.ai la página funciona en modo local: cada navegador guarda sus propios cambios y no carga el diseño compartido ni las fotos del artefacto original.
